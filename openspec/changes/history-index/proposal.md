# 历史索引与承接闭环

把插件从"会话结构阅读器"改为"工作区记忆检索层"：以**工作区级轮次索引**为地基，
检索（找）、呈现（看）、动作（做）三层都读同一份索引。

## 为什么要换地基

现状三个断点都有实证：

1. **搜不到**：正文检索读的是 `buildTurnModel` 的预览字段——提问只存前 80 字、回答只存前 160 字
   （`PROMPT_PREVIEW_LIMIT` / `RESPONSE_PREVIEW_LIMIT`）。命中的前提是关键词恰好落在开头。
2. **搜不全**：`findAcrossSessions` 对每个会话 `break`，只回第一条命中，
   回答的是"哪个会话提过"，不是"提过几次、在哪几段"。
3. **走不回去**：点正文命中执行 `setViewedSessionId`，是在面板里换一个会话看，
   不是回到那个会话的那一轮。

## 范围

- **Windows-only**。不保留 macOS 分支；路径、编码、时区按 Windows 处理。
- 只读宿主公开契约与本地日志，不改日志、不碰宿主私有实现。
- 索引只写 `~/.dsh/topic-map/`，不污染工作区源码树。
- 右侧两个面：**历史右栏**（跨会话结果，`sidebar.right.pane.tab`）与**历史轨**（会话内导航，接管原生
  轮次导航条）；主面板只承载统计、完整续接与配置。

## 分期

| 期 | 内容 | 判定 |
|---|---|---|
| P0 | 索引 + 检索 + 排序 + **历史右栏** + **历史轨接管** + 跨会话落点 + 变更落盘 + Windows 清理 | 3 字以内关键词 300ms 出命中，点一条能回到原会话的那一轮；右侧轨道已被替换且可一键恢复 |
| P1 | 状态三开关 + **断点续接** + 分类实体化 + 整理 + 线索 + 统计 | 断点续接一屏可信：只列真正没完的；改名/拖动持久，模型不覆盖 |
| P2 | fork@turn + 重试 + 引用 + 简报 + **设置页**（模板/预算/权重） | 从第 N 轮派生新会话且首条输入已预填；引用显示 token 估算 |
| P3 | 变更可视化 + 单文件回滚 + agent 按话题召回 | 回滚三态报告准确；冲突文件跳过而非覆盖 |

## 明确不做

- 一键批量回滚（危险写，必须先有单文件可撤销协议；P3 只做单文件）。
- 可视化加码（图保留为会话内视图，本轮不增投入）。
- 跨平台适配。
- 引入 SQLite 或任何原生模块。

## 规程

- 每项先写可失败的行为测试，再实现，再定向回归，再真实 DSH 验证。
- 修改嵌入模块后跑 `build-theme` / `build-viewport` / `verify-bundle`。
- 每项验收通过后独立本地提交；不推送；不提交本机会话内容、密钥与完整日志。
- 宿主契约未经核实前，对应动作只写设计、不写实现。

# 验收要求

编号：F 索引 / S 检索 / V 呈现 / A 动作 / N 非功能 / C 配置。
每条都写"怎么验"，避免"看起来做完了"。

## F — 索引（事实层）

- **F-1 每轮一条记录，存全文。**
  字段：`turn, seq, endSeq, start, end, ms, prompt, response, tools[], files[], commands[], usage{}, model, endReason, interrupted, steps`。
  `endSeq` 是该轮 `turn/end` 事件的 seq（未终结为 `null`），摘要缓存以它为键。
  `commands` 抽取规则：`command/cmd/script` 直取；`code` **仅 shell 类工具**（shell/bash/terminal/exec/powershell/cmd，
  含 `run_shell` 这类分词）直取，其它工具只**解包** `command:` 后的字符串字面量（双/单/反引号，还原 `\n`）；
  **解析失败为空，绝不回退整段 JS**；一次 tool/call 只取第一条；每轮上限 8 条、单条 500 字、按序去重。
  已知限制：`run_code` 里数组包多条命令时只取第一条。
  全文不截断，**不复用** `PREVIEW_LIMIT`（现状 80/160 字）；单轮 `prompt+response` **合计**上限 32k 字符
  （先保提问、余量给回答），超限置 `truncated` 标志。
  验收：索引行数 == 轮数；任取一轮，`prompt` 与日志原文一致。

- **F-2 增量。** `revision` 未变不读事件流。
  验收：连续构建两次，第二次 `listEvents` 调用次数为 0。

- **F-3 可重建且等价。** 删除单会话索引重建，排序后哈希一致。

- **F-4 事实与状态分表。** `sessions/<id>.jsonl` 存事实；`labels/<workspaceId>.json` 存状态与备注，物理分离。

- **F-5 人工优先。** 状态/备注带 `source: 'model' | 'user'`，重跑只覆盖 `model`。

- **F-6 校验。** 索引与日志不一致（轮数变少、seq 回退）时整体重建该会话。

- **F-7 变更快照落盘。** 轮次有 `workspace/changes` 事件时立刻拉 `workspaceChanges.summary` 存进索引；
  明细不可读后保留"曾发生过变更"与文件清单，不伪装成空白。
  验收：历史会话（已 dispose）仍能看到该轮改过哪些文件与 ±行。
  **覆盖边界（事实）**：只有"打开过 / 搜索过"的会话与显式 `/index-build` 会落盘；
  从未访问的历史会话不会自动全覆盖（启动全量重建受 N-4 限制）。

## S — 检索

- **S-1 关键词：** 中文子串；多词 AND；大小写不敏感；不做分词、不做正则。
- **S-2 时间：** 区间 / 相对（今天、近 7 天）/ 单日；按本地时区含头含尾。
- **S-3 结构过滤：** 会话、话题、子类、话题段、工具名、文件、状态（三个开关任一）。
- **S-4 组合：** 以上 AND。

- **S-5 相关度（默认排序）。**
  ```
  score = 3×(命中在提问) + 1×(命中在回答)
        + 0.2×min(该轮命中次数,10)
        + 2×时间新鲜度（今天 1.0 / 本周 0.7 / 本月 0.4 / 更早 0.2）
        + 状态加权（重要 +2 / 已解决 +1 / 待跟进 +0.5）
  ```
  权重走配置（C-2）。**界面必须显示拆解**。
  验收：固定语料下给定查询，排序与手算一致；同分按 `turn` 升序稳定。

- **S-6 分组：** 默认平铺按分排序；可切"按会话"（`提过 N 次 · M 段`）与"按话题"。
- **S-7 延迟：** 8 会话 141 轮 P95 ≤ 150ms；100 会话 1 万轮 P95 ≤ 400ms。
- **S-8 截断可见：** 超上限返回 `truncated` 与总数，界面写"还有 N 条未显示"。
- **S-9 零成本：** 检索与排序不调模型、不需要后台预计算。
- **S-10 范围：** 默认本工作区；可切"全部工作区"，此时按工作区分组。统计恒为单工作区口径。

## V — 呈现

- **V-1 命中列表：** 主面板三行（`会话 · 第 N 轮 · 时间` / `片段（高亮）` / `话题段 · 状态`）；
  右栏两行（`会话 · 第 N 轮 · 时间` / `片段（高亮）`）。
- **V-2 折叠：** 同会话多次命中收成组，展开才列点。
- **V-3 上下文按需：** 展开才取前后各 1–2 轮摘要。
- **V-4 线索视图：** 同主题跨会话按时间排列。
- **V-5 统计视图：** 按大类/子类聚合；第一指标为活跃度（最后活动、活跃天数、未收尾段数），第二层为用量。
- **V-6 跨会话结果面 = 历史右栏：** 两段式注册（`ctx.sidebarRightTabs.register` 定义 +
  `ctx.slots.inject('sidebar.right.pane.tab')` 以定义 **id** 为 key 注册正文），
  `Ctrl+K` 用 `ctx.sidebarRight.openTab(kind, options)` 打开并聚焦输入框（**无 sessionId 参数**）。
  右栏**挤开中间而非覆盖**；降级为 `shell.overlay` 自绘抽屉。宽度与开合见 ui.md §2。
  **默认选中不可设**（宿主无该 API），因此定位是"打开即选中"，不是"默认就是它"；
  两个入口：`Ctrl+K` 与会话标题工具位 `conversation.session.header.utilities` 的常驻图标。
  **边界**：右栏负责跨会话结果；会话内导航由 V-12 的历史轨承担，两者不重复。
- **V-7 空态与失败态：** 无结果 / 索引未就绪 / 宿主不可用各有明确文案。
- **V-8 断点续接（「上次干到哪了」）。** 一屏列出工作区内仍在进行的线头，每条：`话题 › 对话 › 会话`、
  最后活动、最后一轮在干什么（所在话题段 + 规则摘要）、为什么停（失败/中断/待跟进）、一个主按钮。
  **纯规则，不调模型。** 验收：构造"已完成但标记待跟进""失败未处理""久未活动"三类会话，各进正确分组。

- **V-9 模板配置页：** `settings.section` 独立页，可增删改模板、查看变量、选默认；文件落
  `~/.dsh/topic-map/templates/*.md`。

- **V-10 右栏两态：** 空态显示断点续接 Top 3（P0 先显示自动推断的"未完成 / 近期"，P1 接入状态开关后升级）；
  有输入切换为结果列表。两态共用一块区域，不新增界面。

- **V-11 摘要分三层，模型只在第二层花钱。**
  L0 规则摘要（零 token，永远有）：提问首句（≤40 字）+ 工具数 + 文件数 + 结束状态；
  L1 段级摘要（每话题段一次模型调用并缓存，即现有 lane 标题）；
  L2「解释这段」（用户点才调）。
  验收：模型不可用时，列表与续接仍能看到 L0 摘要。

- **V-12 历史轨接管（全部替换原生轮次导航条）。**
  对话区右缘那条"每轮一个刻度、可内部滚动"的原生导航被**永久替换**为历史轨。
  - 原生节点**保留但不可见**（锚点与降级通道），不是移除；我们自己的跳转继续复用它。
  - 三档宽度 40 / 200 / 320，可拖、按会话记忆，默认 200；窄屏自动降细轨。
  - 摘要模式常显轮次摘要；搜索时切「命中模式」（**只标当前会话内**的命中、其余淡出），清空即回；
    跨会话命中一律在历史右栏（V-6），轨不承担。
  - 只跟随宿主**已加载轮次**，不自己算全集。
  - 自检：接管前验证原生容器与 `data-index` 按钮存在；失配则不隐藏、用原生并记诊断。
  - 选择器只认 `data-index` / `aria-label` / `aria-current`（类名是构建 hash）；`data-index` 是合并列表序号，
    **不是轮号**，映射走 `turnOutline` 或 `aria-label`；活动轮读 `aria-current="true"` 反查。
  - 设置页保留「恢复原生导航轨」开关。
  验收：50+ 轮会话中轨道可滚动、点击跳转与原生一致；搜索后命中刻度可见；关闭开关原生立即恢复。

## A — 动作

- **A-1 定位。** 切到目标会话并落到该轮；粗定位标明"为粗定位"。

- **A-2 复制（分类明确 + 反馈可见）。**
  - 命令块：从 `tool/call` 参数取 `command`（**不从散文正则猜**），按序去重，**标 ✓/✗ 与退出码**。
  - 代码块：回答 markdown 的 fenced block；片段：命中处前后约 40 字；整段：该轮完整回答。
  - 主按钮：有命令 →「复制命令」；无命令 →「复制结论」；片段/整段进次级菜单。
  - 反馈：toast `已复制 3 条命令（含 1 条失败）` +「查看」预览；失败给原因。

- **A-3 状态（三个开关 + 一行备注）。** `待跟进 / 已解决 / 重要`，可叠用。
  **只在 V-8 消费时才实现**；不被消费则不做。

- **A-4 引用（单档 + 摘要展开）。**
  - **只有一档**：插入指针 `@第33轮对话〔4c42ff36#33〕`，不带后缀、不拼正文。
    （曾设计"摘要/全文"两档，按用户决定**取消**；`·全文` 后缀不再解析。）
  - **指针必须自带可解析句柄** `<会话前缀8位>#<轮号>`：裸 `@第33轮对话` 对模型毫无意义。
  - **自动展开**：宿主在 `system-prompt/assemble` 扫描最近 20 条人类消息里的 `〔8hex#N〕`，
    最多 3 个，`interpolate:false`；注入的是该轮**摘要**（≤400 字，`/turn-digest`，按轮次缓存）。
  - 摘要生成失败 → 降级为"该轮回答前 400 字"并在块首标注，**插入流程不受影响**。
  - 摘要在 `/turn-detail` 成功后**后台预生成**（并发 1、在途去重），先看详情再引用通常零等待。
  - 手动勾选才带：提问全文 / 回答全文。**工具结果永不默认**，仅"失败命令的错误首行"。
  - 插入前用 `tokenMeter` 估算并显示 `约 +N tokens`；超过 `citeTokenBudget`（默认 **5000**，可配置）须二次确认。
  - 载体是结构化引用块（可折叠回指针），不是拼接文本。
  - 验收：插入含 3 轮全文的引用被拦下要求确认；取消后输入框无残留。

- **A-5 fork@turn。**
  - 前置四条件：有 `startSeq`；会话可读；会话不在生成中（在生成则只能分叉到已落盘部分并提示）；
    边界语义已核实：**`atSeq` 是 inclusive（含该 seq）**，所以"从第 N 轮之前分叉"要传 `该轮 startSeq - 1`。
  - 标题自动带 `（从「原标题」第 N 轮分叉）`；自动进「未归类」。
  - 血缘 `{parentSessionId, atSeq}` **自存标签层**，不依赖宿主。
  - 同一轮 fork 超过 3 次时提示。

- **A-6 重试。** = `fork(该轮之前)` + **重提该轮原始 prompt**（重跑意图，不重放工具调用）。
  只在 `endReason ∈ {error, max-tokens, interrupted}` 出现；一次点击一次执行，不自动重试；
  成功判定 = 新会话该轮 `endReason === 'completed'`。

- **A-7 看变更。** 三层：文件清单 + ±行 → hunk 展开 → 该文件在演化史中的位置；明细不可读时明确提示。
- **A-8 简报。** 模板驱动（V-9），生成 Markdown 落盘可再编辑；输入只给摘要与指针，不给全文。
- **A-9 整理。** 改名/移动/合并/拆分，写标签层 `source: 'user'`；模型只提议。
- **A-10 状态驱动主按钮。** 活跃→定位；失败→重试；有变更→看变更；已标记→复制。
- **A-11 无静默失败。** 不可用要写原因，失败要给人话错误。
- **A-12 回滚（P3，先单文件）。** 基准 = 该轮落盘的 diff；写前比对当前内容哈希，不符则**跳过不覆盖**；
  三态报告（已恢复/部分恢复/未恢复）+ 逐条原因 + 可撤销。
- **A-13 agent 召回（P3）。** `tools.register` 注册只读召回工具，用**话题/状态**检索（"我标了待跟进的那件事"），
  不重复平台已有的 `session_search` 全文检索；返回摘要 + 指针 + 预算截断。
- **A-14 排序与复制的可见性。** 排序条常驻、口径可切；每条显示分数来源；复制结果与失败都可见。

## N — 非功能

- **N-1 Windows-only。** 不保留 macOS 分支；路径比较按 NTFS 不区分大小写；UTF-8；时间存 epoch ms。
- **N-2 隐私。** 只写 `~/.dsh/topic-map/`；可整目录删除；不新增网络出口。
- **N-3 降级。** 索引缺失/损坏 → 回退旧 `/find`；模型不可用 → 规则摘要；绝不因索引问题白屏。
- **N-4 预算。** 索引体积 ≤ 原文日志 1.2 倍；启动不做全量重建。
- **N-5 契约诚实。** 未核实的宿主契约只写设计不写实现（`openSession` 的 target 形状、`fork.atSeq` 语义、
  composer 写入、工具注册、`workspaceChanges` 历史可读性）。

## C — 配置

- **C-1** `citeTokenBudget`（默认 5000）。
- **C-2** 排序权重 5 项（默认见 S-5）。
- **C-3** 模板目录与默认模板（V-9）。
- **C-4** 索引目录与保留期（复用现有 90 天清理口径）。

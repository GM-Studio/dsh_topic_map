# 界面规格

## 0. 结论：右侧两个面，性质不同

**面 A 历史右栏（跨会话结果）——平台有座位。** 已核实：

- `ctx.sidebarRightTabs.register({ id, kind, title, guide? })`：注册 tab **定义**；
- `ctx.slots.inject('sidebar.right.pane.tab', ...)` + `key: 定义 id`：注册正文（**key 是 id，不是 kind**）；
- `ctx.sidebarRight.openTab(kind, { params, revealIfOpened, replaceTab })`：打开并选中（**无 sessionId 参数**）；
- `rightbar` 是"中间内容为它让出空间"的列，不是浮层覆盖。

**默认选中不可设**——宿主没有 `defaultTab`/`setActive`，新列默认页由 guide 条目决定。所以右栏不会默认是我们的，
定位是**「打开即选中」**：两个入口都直达本页——

1. `Ctrl+Shift+H`（备选 `Alt+H`）；**不绑定 `Ctrl+K`**——它在 Chromium/宿主里是搜索默认键，抢不过也不该抢；
2. 会话标题右侧工具位 `conversation.session.header.utilities` 的常驻图标。

**运行时已验证**（真实 DSH）：图标出现、面板打开、搜索出结果。
注意：客户端 Service 目录**不列** `sidebarRightTabs` / `sidebarRight`，但它们在运行时存在——不能据目录判断可用性。

不采用"启动时自动展开右栏"：那会在每次开应用时抢注意力。

降级路径（若 tab 注册被拒）：`shell.overlay` 自绘右侧抽屉，交互不变，只是不挤开中间。

**面 E 历史轨（会话内导航）——平台没有座位。** 对话区右缘那条轮次导航由对话组件自绘，
115 个 slot 里没有任何 nav/rail 座位。所以 V-12 是 **DOM 级接管**：隐藏原生（保留节点作锚点与降级通道）
后在原位挂载自己的轨。失败可逆——最坏是回到原生，不是白屏。详见 §10。

## 1. 五个面

| 面 | 位置 | 职责 | 期 |
|---|---|---|---|
| **A 历史右栏** | `sidebar.right.pane.tab` | 查 + 扫 + 就地动作 | P0 |
| **B 主面板** | `main` + `sidebar.panellist` | 统计 / 完整续接 / 线索时间线 / 配置 | P1 |
| **C 轮尾菜单** | `conversation.chat.turnTail` | 就地动作（引用/分叉/标记/复制/看变更） | P2 |
| **D 会话视图** | `conversation.view` | 单会话泳道图（保留） | 已有 |
| **E 历史轨** | 对话区右缘（接管原生轮次导航条） | 命中刻度 + 轮次摘要 + 跳转 | P0，见 §10 |

原则：**右栏负责"扫"，主面板负责"读"，轮尾负责"就地做"，会话视图负责"看结构"。**

## 2. 面 A：历史右栏

### 2.1 尺寸与开合

- 默认宽 360px，可拖 320–560px；宽于 480px 时列表自动升为三行。
- 两种模式：**自动**（默认，选中结果并执行动作后收起）、**钉住**（常驻，中间让出空间）。标题栏图钉切换。
- 打开：`Ctrl+K`；或会话标题右侧工具位的历史图标。
- 记忆：模式与宽度按会话记（复用现有 sessionStorage 口径）。

### 2.2 两种状态

**空态（未输入）—— 断点续接 Top 3**
（P0 先显示自动推断的"未完成 / 近期"三条，P1 接入状态开关后升级为待跟进优先）

```
┌ 历史 ──────────────── 📌 ⤢ ┐
│ ⌕ 搜对话…            Ctrl+K │
├─────────────────────────────┤
│ 待跟进                      │
│ ◐ 索引方案      2 天前·T78  │
│   最后：在写 spec  [继续] ⋯ │
│ 未完成                      │
│ ● 端口冲突      5 天前·失败 │
│                    [重试] ⋯ │
├─────────────────────────────┤
│ 查看全部 →                  │
└─────────────────────────────┘
```

**查询态 —— 两行紧凑列表**

```
│ 插件开发 › T37      2 天前  │
│ 把左栏改成**三级树**…       │   ← 命中处高亮
│ ─────────────────────────── │
│ 合并测试 › T4       5 天前  │
│ 端口 **冲突**…              │
```

- 行高 56px；第一行 12px 次要色，第二行 13px 正文。
- 选中某行：**就地展开**一行上下文预览（前后各 1 轮摘要）+ 三个动作（定位 / 引用 / ⋯），不跳走。
- 「详情」链接 → 主面板（放大版）。

### 2.3 键盘

| 键 | 行为 |
|---|---|
| `Ctrl+K` | 打开右栏并聚焦搜索框 |
| `↑ ↓` | 选择结果 |
| `↵` | 定位到该轮（离开当前页，唯一跳转动作） |
| `Ctrl+↵` | 引用到当前输入框 |
| `Shift+↵` | 从这轮分叉 |
| `Ctrl+C` | 按 A-2 规则复制（命令优先） |
| `Tab` / `→` | 就地展开上下文 |
| `Esc` | 收起右栏（自动模式下） |

### 2.4 底部状态条

`12 条 · 相关度 · 128ms` + 截断提示 `还有 87 条`（可点进主面板看全部）。

### 2.5 详情请求口径
点「详情」调 `POST /api/topic-map/turn-detail {sessionId, turn, before:1, after:1}`：

- 用返回的 `turn.prompt/response` 渲染摘要与全文展开，`usage / model / steps / endReason` 进元信息行，
  `changes.files` 进变更清单；
- 用 `neighbors` 渲染前后各一轮的 `promptHead`（点击可切到那一轮）；
- 用 `label` 渲染三开关初值；
- **定位用 `turn.seq`**，不是轮号；
- 失败分级：404「该轮已不存在」、502「读不到该会话」、504「读取超时」——都写出来，不静默。

### 2.6 复制弹窗

**「复制命令」不再直接写剪贴板**，先弹窗让人看见要复制什么。

```
┌ 本会话命令（共 137 条）                         ✕ ┐
│ 1.  npm test                                    ⧉ │
│ 2.  node scripts/test-all.mjs                   ⧉ │
│ …                                                  │
├────────────────────────────────────────────────────┤
│ [上一页] 第 2 / 7 页 [下一页]   [复制本页] [复制全部] │
└────────────────────────────────────────────────────┘
```

- 数据：`POST /session-commands {sessionId, offset, limit:20}`，**分页走接口，不拉全量**；
- **一行一条完整命令**，行首是全会话连续编号 `seq`（第 2 页从 21 起），**不折行**，超宽省略号 + `title` 看全文；
- 每行右侧复制单条；`ok === false` 标红，`null` 不标（索引未存成败）；
- 空态 `本会话没有命令`；ESC / 点外部关闭。
- 「复制结论」同样弹窗预览全文后再复制，解决"不知道复制了啥"。

## 3. 面 B：主面板（放大版）

从侧栏「查看全部」或侧栏图标进入。三页签：

| 页签 | 内容 | 期 |
|---|---|---|
| **续接** | 完整断点续接（分组、上限 10 + 全部） | P1 |
| **线索** | 同一套查询 + 多条件 chips + 分组切换 + 批量选择 | P1 |
| **统计** | 大类/子类聚合（活跃度为主、用量为辅）+ 时间范围 + 导出 | P1 |

配置不在这里，在设置页（面 E，`settings.section`）：模板、`citeTokenBudget`、排序权重、索引状态与重建。

**同一套结果，两种尺寸**：侧栏两行、主面板三行 + 详情抽屉；不另做一套数据。

## 4. 面 C：轮尾菜单

对话中每一轮尾部一个 `⋯`，菜单五项：引用 / 从这轮分叉 / 标记 / 复制命令 / 查看变更。
只放一个入口，不铺按钮组；菜单项按 A-10 状态规则置灰并写原因。

## 5. 面 D：会话视图

现有泳道图保留，不再加可视化投入；入口从主面板或侧栏「在会话视图中打开」。

## 6. 状态与失败态（所有面共用）

| 状态 | 文案与行为 |
|---|---|
| 索引未就绪 | 「正在建立索引（n/m 会话）」+ 进度，不空白 |
| 无结果 | 「没有找到」+ 建议（放宽时间 / 换关键词 / 看续接） |
| 宿主不可用 | 「当前会话无法跳转：…」写明原因 |
| 截断 | 「还有 N 条」可点开 |
| 定位失败 | 「已粗略定位到第 N 轮附近」明确标注 |

| 编号 | 动作 | 触达点 |
|---|---|---|

| A-2 | 复制 | 侧栏 `Ctrl+C`、轮尾菜单 |
| A-3 | 状态 | 侧栏 `⋯`、轮尾菜单、主面板详情 |
| A-4 | 引用 | 侧栏 `Ctrl+↵`、轮尾菜单 |
| A-5 | fork | 侧栏 `Shift+↵`、轮尾菜单 |
| A-6 | 重试 | 续接卡片主按钮 |
| A-7 | 看变更 | 侧栏 `⋯`、轮尾菜单、主面板详情 |

## 8. 视觉基线

- 字号 12/13/14 三档；行高 56（两行）/ 72（三行）。
- 颜色只用现有主题令牌，不新增色板。
- 命中高亮用背景色而非加粗，避免长片段变花。
- 所有可点元素键盘可达，焦点环可见。

## 9. UI 层验收

1. 右栏在 360 / 480 / 560 三个宽度下不发生内容溢出或截断错位。
2. 空态、无结果、索引未就绪、截断四种状态都有可见文案。
3. 键盘全链路可完成"搜 → 选 → 引用"，不碰鼠标。
4. 自动模式下动作完成后右栏收起且焦点回到输入框。
5. 真实 DSH 截图各一张：空态、查询态、钉住态。

## 10. 面 E：历史轨（替换原生轮次导航条）

**定位**：对话区右缘那条原生导航（每轮一刻度、内部滚动）被**永久替换**。视觉上不再是"刻度条"，
而是"这条会话的历史导航"。

### 10.1 三档宽度

| 档 | 宽度 | 内容 |
|---|---|---|
| 细轨 | 40px | 只留刻度；悬停浮出摘要 |
| 标准 | 200px（默认） | 刻度 + 轮次摘要，一屏约 12 条 |
| 宽 | 320px | 摘要 + 状态（失败/有变更/已标记）+ 命中片段 |

可拖、按会话记忆；窄屏自动降细轨。

### 10.2 两态

- **摘要模式**（默认）：每行 `刻度 + 第 N 轮 + 摘要首句`。
- **命中模式**（搜索中）：**当前会话内**的命中轮次高亮并显示命中片段，其余淡出；清空搜索回到摘要模式。
  跨会话命中不在这里显示，一律进历史右栏。

### 10.3 交互

| 操作 | 行为 |
|---|---|
| 点击一行 | 跳到该轮（复用 A-1 定位） |
| 悬停 | 高亮该轮，浮出 2 行摘要 |
| `⋯` | 引用 / 分叉 / 标记 / 复制 |
| 拖宽度 | 三档吸附 |

### 10.4 边界
- 只列宿主**已加载**的轮次；未加载的不显示，避免"点了跳不过去"。
- 原生结构：`[data-conversation-scroll] > nav > div(滚动容器) > div(marks) > button[data-index]`；
  **`data-index` 是合并列表序号，不是轮号**，映射靠 `turnOutline` 或 `aria-label`。
- 活动轮没有公开快照，读原生 `button[aria-current="true"]` 反查。
- 失败轮、有变更轮、已标记轮各有状态标记。
- 自检失配 → 不接管、用原生，并在诊断里记一条。
- 设置页「恢复原生导航轨」开关，切换即时生效。

## 11. 标签读写口径（P1-1 客户端）

只消费**扁平 map**：`{ "sessionId#turn": { followUp, solved, starred, note, source, updatedAt } }`。

- 全量读 `POST /labels`；单条读也是同形状（`count` 0/1）。
- 写入用 `POST /label-set` 返回的 `{key, label}` **就地替换缓存**——不要自己维护 `source` / `updatedAt`。
- 不必区分历史 `{labels:{…}}` 包装：Host 读侧已归一。
- 三个开关是**独立布尔、可叠用**；排序权重相加（rank 已实现），界面上按 `重要 → 已解决 → 待跟进` 展示。
- 切换后要能立刻反映在三处：列表徽标、断点续接分组、统计口径。

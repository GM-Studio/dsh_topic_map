# 工作区统计与当前会话跳转修复

## 需求

1. 顶栏明确展示所选工作区的规模：轮次按已归类、未归类会话去重汇总，话题数对应左树顶层分类。当前会话数据只可修正其所属工作区；加载中不得展示上个工作区的数字。
2. 仅当当前浏览会话、宿主会话、已加载 payload 身份一致，且在会话详情层时，显示和允许跳转。历史会话详情和展开的轮次详情均不提供跳转。
3. 跳转先通过 Session Controller 加载目标 startSeq，再从 Conversation 的 Chat target 获取实时锚点，切换 Chat 后复用已核实的原生轮次导航，最终对齐该轮可见用户输入。
4. 加载失败、缺失锚点或精确用户行时明确提示失败，不把过程行或下一轮视为成功；异步迟到结果不得覆盖后续选择。

## 设计与边界

- 统计继续复用工作区归类结果。显式切换工作区刷新全部轮数；默认打开只刷新当前会话。未归类会话同时返回已读取的轮数，避免漏计。
- 工作区请求以序号隔离；轮次跳转以请求身份与当前浏览资格隔离。
- 宿主契约依据本机 DSH `0.2.1-rc.5` 的 `dsh-client-ui-conversation`、`dsh-client-ui-chat` 与 Session Controller 实现。Chat 的阅读位置 Map 是私有实现，不直接访问。
- 原生导航 DOM 契约：中文/英文轮次导航 nav、带 data-index 的精确 aria-label 按钮。虚拟轨道间距从可见按钮实际几何计算；只点击目标轮次的准确标签。
- 不涉及会话分支、恢复、分类模型或原始会话内容修改。
